# 五速鞋可选客户端模块

配合钓具助手保存的五速鞋开关，把客户端原跑步速度临时乘三，计算完成后恢复原基准；走路速度不变。沿用游戏当前的跑步按键设置。没有安装此模块时服务端可以保存开关，但不会改变移动速度。

## 构建与启用

在Visual Studio的x64 Native Tools命令行中执行build.cmd。生成out/winmm.dll与out/rf4_gear_winmm_system.dll。模块只在rf4_x64.exe中工作；启动时读取同目录rf4-gear-assistant.ini的gear_assistant.enabled，缺省关闭。

```ini
[gear_assistant]
enabled=1
```

将生成的两个DLL与上述ini放到游戏可执行文件旁。已有其他winmm.dll接入模块时，应整合源码入口，不直接覆盖已有模块。关闭enabled后重新启动游戏可停用此模块。

游戏内私聊钓具助手发送“五速鞋 开/关”，只发“五速鞋”查询。启动时从服务器静默恢复当前账户设置，不重复显示登录状态；手动查询和开关回复照常显示。模块读取钓具助手的现有五速鞋操作回执和启动同步响应，使用邮件ID顺序防止旧消息覆盖新设置。

菜单、操作回执和状态查询沿用钓具助手的原有格式。普通回复不附加同步状态，模块不改写聊天文本。

## 兼容范围

客户端基线4.0.25034。模块通过IL2CPP元数据解析方法/字段并核对入口指令；不匹配时不会启用加速。只包含移动与设置同步，不包含远程设施或抄网。此目录不包含游戏资源、客户端二进制、Steam登录修复或网络路由。

初始化等待核心程序集就绪，先注册后台线程，再枚举程序集和安装入口，完成后注销该线程。诊断日志默认写入当前用户临时目录的rf4-gear-assistant-进程号.log，也可在ini的gear_assistant节用log指定路径。
