# 官方投距技能效果对照表（cast-skill-official-effects）

来源：**客户端 4.0.25034** 本地化资源逐字提取，非自造标定。
本文是 `skill_cast_effect_def`（迁移 00060 + `ensureCastSkillEffects` 种子）的审计依据。

## 提取方法（可复现）

1. 技能文案 key 形如 `ability_<node_id>`（名称）与 `ability_<node_id>_<level>`（各级描述）。
2. 16 语言 JSON 块位于 `Game/rf4_x64_Data/resources.assets`（359MB）；简中块起始偏移
   `~289500774`，德语块 `~[284.9M, 289.5M)`（德语原名用于鉴别中文误译，见下）。
3. 按 `"ability_<id>":{"systemId":...}` 字节模式定位，正则抽取含 CJK 字符的条目，
   共 680 条简中技能文案。
4. 等级阶梯核对：对每个节点逐级打印 `ability_<id>_<n>`，全部为 +5%/级 线性阶梯
   （无递减/台阶）。

## 已知局限

- 传统轮的**轻型/重型**细分（718/1008 vs 721/1020）在 `fopbhlmkcpe` 里同为 type 4，
  无法按装备区分；同一 gate 槽位取最高一行结算（学满两行不叠加）。
- 「鱼的可控性 +3%/级」「搏鱼能量消耗 -5%/级」属搏鱼相位，本表不种、不结算
  （Out of Scope，另立 spec）。
- 诱饵笼类 +10%/级（305/317，官方文案「抛掷距离+10%」）走独立喂食装备通道，
  本版不种。

## 对自造鱼侧行的清理

`skill_fish_effect_def`（00038，全 `source='local-sim'`/confidence 0.45）给上表节点
配的自造鱼口效果与官方文案矛盾（例：701 被映射成 ecology_interest +3.5%/级）。
`ensureCastSkillEffects` 在启动路径按生产顺序（鱼口 ensure 之后）删除上表全部节点的
鱼侧行；官方文案本身含鱼侧语义的节点（如 301/502/504/506/508/510 稀有鱼/渔获量类）
不受影响。
