# 钓获结算事务

每尾鱼使用鱼 GUID 保存一次结算回执。首次成功收鱼时，经验与等级、钓法熟练度、装备磨损、损伤记录和回执在同一事务提交；任一步失败会回滚，原鱼保留供重试。

重复请求和进程重启后读取同一回执，不再次增加经验、熟练度或磨损。等级及钓获通知仅在首次提交成功后发送。旧回执保存的加成分解和技能增量继续可读；没有技能增量字段的旧回执沿用原兼容值。

入护、放生和护网库存仍通过各自业务入口处理，本事务不把这些操作合为同一次提交。

协议目标为客户端4.0.25034，服务端测试使用已有14/4及结算对象结构构造请求。真实客户端断线重连、重复请求、护网满额、售鱼及放流仍需人工验收，服务端测试不能代替这些结果。
