# 护网与钓获记录同步

入护复用容量校验事务，同时保存护网、钓获记录并消费待处理鱼。保存失败保留原鱼；放生沿用 `release_xp_ratio`，用鱼标识保存奖励回执，失败不清除待处理鱼，重试不重复奖励。

登录时只恢复已经完成 14/4 结算、尚未选择入护或放生的鱼，并按原结算回执入护，不再发经验。在线读取护网不会替玩家选择入护。护网满时保留原鱼并阻止新抛竿；腾出位置后重试。已入护、售出、删除或放生的鱼不会由旧快照再次生成。

护网数量、分页、详情、删除和售鱼使用当前所属玩家的数据。导入鱼保留原字段，只在响应中更新标识、容器与版本；背包和已建模的原生容器分别筛选，避免同一物品出现在多个容器。

目标客户端为 `4.0.25034`。服务端测试覆盖重复请求、重启、失败回滚、满护网和导入物品同步；真实客户端断线重连、入护、放生、售鱼和删除仍待验收。
