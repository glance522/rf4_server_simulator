# 装备磨损对拍：官服 4/22 快照时间序列 vs 模拟器（2026-11-11）

> 性质：一次性分析快照。数据源：四场官服会话的 4/22 装备快照 46 帧
> （lure2 19 / marine 19 / float 10 / bottom 4，`logs/captures/official_trace/`），
> 用 `tmp_analysis/wear` 解出每帧所有物品形组件的 `nmidlgejlcp`（剩余完好率 0..1）、
> workmanship、强度字段，按 guid 连成时间序列（`logs/captures/wear_*.tsv`，logs/ 不入库）。
> 精确速率用 trace 时间戳（`trace_路亚3.txt` 每帧 epoch）计算。行号按当日 main ed281bb。

## 一、结论先行

**抓包里有装备磨损信息，而且是逐帧连续下发的**。四条硬结论：

1. **磨损只按"受力时间"扣**：17s 搏鱼窗口所有磨损件单调下降（轮油/主齿轮/导环
   ≈ 0.0004%/s）；而脱钩后 92s 空竿收线（74 条 14/7 收线遥测）**全部零件零磨损**。
   磨损 ∝ 搏鱼/受力时长，与抛竿次数、收线时长无关。
2. **结算无跳变**：n.pike 上鱼经 14/4/14/5 结算后，下一场搏鱼首帧的 durability 与
   结算前连续（差值 ≈ b_gill 搏鱼本身的开销），不存在"每尾鱼扣一笔"的离散磨损。
3. **新件恒 1.0 不动**：手柄（category 4）、旋钮（34）全程 1.000000——这些部件
   在正常钓鱼里**不磨损**（至少低于 1e-6/帧分辨率）。
4. **钩不磨损**：n.pike（4.3kg，牙鲈）上岸全程，三本钩 durability 纹丝不动
   （0.999924）；float 场 2 尾上岸鱼钩磨 1e-6。钩的损耗走断钩事件，不走渐进磨损。

1. **触发口径**：我们每竿必扣（空竿也扣），官方只按受力时间——空竿收线 92s 零磨损
   是直接反例。`perRod` 通道应改为"搏鱼受力秒数"通道（14/8 遥测 f23/f24 收线做功、
   线载统计是现成输入，目前服务端丢弃）。
2. **下发表演**：官方在搏鱼中每帧 4/22 连续下发 durability（客户端能看见数字掉）；
   我们 4/22 快照里耐久不随搏鱼变化（结算才落库）。补齐受力磨损后可顺带逐帧下发。
