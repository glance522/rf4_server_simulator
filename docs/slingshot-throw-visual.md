# 弹弓抛饵协议与行为

## 命令链路

```text
13/4  拿起弹弓
13/1  装填一份窝料，服务端拆出装填子实例并写入弹弓的装填引用
13/5  抛出一发：服务端消耗装填子实例、写入窝料账本并返回 805
13/6  请求钓组全量快照
```

弹药格里真正被消耗的是 `13/1` 拆出的子实例，不是背包来源堆。窝料账本、
配方查询和物品变化都必须使用这个子实例的 GUID。

## 805 响应字段

`805 / lmbomkliaad` 包含：

1. 抛投距离；
2. 散布百分比；
3. 姿态块；
4. 物品实例更新数组；
5. 可选的抛出物实例数组；
6. GUID 移除数组。

该响应没有世界坐标或朝向字段。客户端自行计算飞行表现，服务端能够控制的是距离、
散布和物品变化，不能直接指定飞行目标点。

## 服务端行为

- `13/5` 只处理装填槽中的窝料或 PVA 物品，其他物品不会进入窝料账本。
- 每发消耗装填槽中的一份，并用装填子实例 GUID 查询自制配方。
- 制作时用料记录在背包来源堆；装填或挂饵拆出新实例时，配方会同步复制到子实例。
- 投放账本冻结当时的实际用料，之后物品被消耗或删除不会影响仍然存活的窝。
- 窝账与钓点、5 米网格、通道和会话内 CallID 关联；重复上报不会重复投放。
- 13/5 的窝料投放幂等键包含弹弓 GUID、会话号和 CallID，避免重连后 CallID
  重新编号撞到旧记录。

## 可调参数

| 参数 | 缺省 | 说明 |
|---|---:|---|
| `handitem_throw_scatter` | 3.0 | 805 散布百分比 |
| `handitem_throw_pose` | 1 | 是否下发姿态块 |
| `handitem_throw_projectile` | 0 | 是否额外下发抛出物实例；客户端通常会自行绘制 |
| `handitem_throw_selfclean` | 0 | 是否把临时抛出物加入移除数组 |
| `handitem_throw_dist_force` | 0 | 用固定距离覆盖客户端上报值；0 表示不覆盖 |
| `handitem_throw_land_cell` | 0 | 是否用服务端计算的落点作为窝账格子 |
| `handitem_throw_fallback_yaw` | 0 | 没有浮标方向时的兜底偏航角，单位为度 |

## 已知限制

原生客户端会根据本地瞄准状态生成饵团飞行方向。805 没有可下发的坐标或朝向，
因此服务端无法仅靠协议修正视觉方向。当前实现保证扣料、配方、窝账和鱼口判定一致，
视觉方向仍以客户端原生行为为准。

## 回归覆盖

- 13/1 装填后，装填子实例继承来源堆配方；
- 食笼/PVA 拆分子实例后，配方随子 GUID 复制；
- 13/5 投放账本保存装填子实例的实际用料；
- keepalive 持续推进在线窝料钟；
- 13/5 的扣料、幂等和 805 响应结构保持通过。
