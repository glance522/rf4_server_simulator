# 欢乐时光

默认开启，可在鱼群规则页独立关闭。每个角色按上海自然日累计60分钟实际在线钓鱼时间；持有有效鱼竿且钓组在水中时计时，离线和暂停不消耗，遛鱼期间继续计时。同一角色的多个会话共享一份时长。

生效时钓获基础经验额外增加50%，最终吃饵接受率相对提高10%，熟练度增长触发率相对提高25%并封顶95%。低兴趣鱼饵的最终接受率不超过10%，禁饵仍然排除；永久熟练度上限和单次增长量保持原规则。以上为本地玩法数值。
